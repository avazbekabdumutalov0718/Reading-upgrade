# V23 Speed Listening Auto-Check

- Speed Listening lessons now accept a YouTube transcript paste per video.
- The existing ListeningEngine automatically creates 15 Gap Filling + 15 Dictation items from the transcript.
- Timestamped transcripts produce timestamped audio segment buttons.
- Gap Filling uses normalized exact answer checking.
- Dictation ignores punctuation/case and accepts >=90% word-level similarity.
- Each section has a Check button, per-item correct/incorrect feedback, and a 15-point score.
- The lesson shows a combined 30-point score and percentage after both sections are checked.
- The 30-day library shows readiness and latest score for each lesson.
- Raw transcript text is not stored; generated question/answer/timestamp data is saved through the existing Listening progress cloud state.
- Site still defaults to Reading Upgrade on startup.
- Listening thumbnails keep the V22 image/fallback fix.

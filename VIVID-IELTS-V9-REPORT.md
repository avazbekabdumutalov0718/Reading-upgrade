# VIVID IELTS Unified V9

- Global brand changed from IELTS MAX INTENSIVE to **VIVID IELTS** across the public site and imported exam bridge pages.
- Login rebuilt in the original SITE/VIVID style: video visual panel, Log in / Sign up tabs, show-password, remember UI, password-reset request and Google OAuth button.
- Existing Supabase project/database is retained so current progress data and RLS continue working. Google OAuth uses the same current project.
- Optional study preparation gate added after authentication: **Darsni duolar bilan boshlash** or **O‘tkazib yuborish**. The 99-count tasbeh + 3 duas remain available but are no longer compulsory.
- New **12 Tenses** section added to Grammar: all 12 English tenses with EN/UZ explanation, forms, IELTS use, time markers, 3 translated examples and 8 mixed checks per tense. Progress is included in the account cloud snapshot.
- Reading Passages, Listening Tests, Reading Booster, Listening Boost, Writing Booster and all previous V8 features remain.
